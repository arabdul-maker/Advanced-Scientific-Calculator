
# 🧮 Advanced Scientific Calculator

A scientific calculator built using Python and Streamlit.

## Features
- Basic arithmetic
- Scientific calculations
- Trigonometry and logarithms
- Square roots and factorials
- Calculation history
- Degrees and radians modes
- Error handling
- Dark-themed interface

## Technologies
- Python
- Streamlit

## Run locally

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the application:

```bash
python -m streamlit run calculator_app.py
```
